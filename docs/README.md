## Documentation philosophy

The main README stays short enough for a new player to understand what DSR does and how to get started. Detailed configuration, compatibility and implementation notes live here instead of expanding the project front page indefinitely.

DSR's gameplay contract is intentionally stable across renderers and companion mods: Dramatic Sky Ride owns movement, collision, altitude, progression and mounted state; optional integrations provide presentation or surrounding ecosystem features.
